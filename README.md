## ⚡ Featured Experiments & Batches

1. **Bridge IT — AgriTech Digital Marketplace**
   - *Farm to boardroom. One marketplace, AI doing the haggling.*
   - Dual-portal marketplace connecting farmers directly with industrial buyers with protected minimum margin floors (cost + 20–30% margin).
   - Pitched to the Biotech-KISAN Hub (DBT, Govt. of India).

2. **Cafe La Roche — Campus Canteen Pre-Order Platform**
   - *Order in lecture. Pick up when it ends.*
   - Full-stack canteen digital pre-ordering and kitchen queue management system.
   - Restricted college-email login (`@sakec.ac.in`), live Razorpay online payments, and instant token generation.
   - Deployed on campus server: [http://121.241.29.115:5050](http://121.241.29.115:5050)

3. **Aegis-Match**
   - Sub-microsecond (380ns P99) limit order book and price-time priority matching engine in C++20 with zero runtime heap allocations.

4. **Krypton-KV**
   - Crash-resilient LSM-tree transactional storage engine processing 185k operations/sec with automated ledger reconciliation.

## 🚀 Local Development

```bash

cd BB-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```
